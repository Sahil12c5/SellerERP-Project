SellerERP – Import Export ERP System

SellerERP is a web-based ERP (Enterprise Resource Planning) application designed to help import–export sellers efficiently manage their products, orders, reports, and profiles.
The application is built using Java Web Technologies and follows the MVC (Model–View–Controller) design pattern to ensure scalability, maintainability, and clean separation of concerns.

📌 Project Overview

The system allows sellers to:

Register and securely log in

Manage products and orders

Handle reported products

Maintain seller profiles

Operate through a centralized seller dashboard

This project demonstrates real-world ERP workflows implemented using JSP, Servlets, JDBC, and MySQL.

🗄️ Database Design

The system uses MySQL with the following core tables:

Users – Seller authentication and profile data

Products – Product details managed by sellers

Orders – Order information

Reported Products – Product issue reporting

Database connectivity is handled using JDBC.
